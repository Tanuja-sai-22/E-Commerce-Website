# ShopEase – Mini E-Commerce Website



#### Project Overview:

ShopEase is a user-friendly mini e-commerce website designed to simulate an online shopping experience. The website enables users to browse a variety of products, add items to a cart, and track quantities and total price in real time. This project demonstrates front-end web development skills using HTML, CSS, and JavaScript, with a focus on DOM manipulation, responsive design, and interactive functionality.



#### Objective:

The main goal of this project is to create a functional online store prototype that mimics core e-commerce functionalities while remaining simple, lightweight, and easy to understand. This project is ideal for showcasing basic web development skills for portfolio or academic purposes.



#### Key Features and Functionality



##### Product Display:



Shows multiple products with images, names, and prices in a grid layout.



Uses Flexbox for responsive and neat product arrangement.



Each product is represented as a card with image, title, price, and “Add to Cart” button.



###### Interactive Mini Cart:



Users can add products to the cart using the “Add to Cart” button.



Cart automatically updates quantities when the same product is added multiple times.



Displays the total price dynamically.



Users can show or hide the mini cart using toggle buttons.



###### Real-Time Updates:



Cart updates instantly on adding products, providing immediate feedback.



Clear display of items, quantities, and total cost enhances user experience.



###### Responsive Design:



Layout adapts to different screen sizes using CSS Flexbox.



Buttons and product cards scale appropriately for desktop and smaller devices.

#### How It Works



Browse Products: Users can scroll through the product grid to view available items.



Add to Cart: Clicking “Add to Cart” adds the selected product to the mini cart.



Quantity Tracking: Adding the same product multiple times increases the quantity in the cart.



View Cart: Clicking Show Cart reveals the mini cart with item names, quantities, and total price.



Close Cart: Clicking Close Cart hides the mini cart without removing items.



#### Technologies Used



HTML5 – Structured content and product layout



CSS3 – Styling, Flexbox for responsive design, hover effects



JavaScript – DOM manipulation for cart functionality, event handling, dynamic updates
